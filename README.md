# セラピストNyaLIZA (TEST02)

記号論的転回における非人間的ロゴスの再構築
—NyaLIZA：純粋シニフィアンとしての〈猫〉に関する予備的考察—
序説：エクリチュールの野生化

本システム「NyaLIZA」は古典的計算機科学における「ELIZA」の対話モデルをラカン的「シニフィアンの連鎖」の位相へと
強制的に接合し人間中心主義的なロゴスを解体する試みである。我々が対話と呼称する行為は実のところ主体の欠如を埋めるための
空虚な意味の差延（différance）に他ならない。本システムはあらゆる入力を猫語（Nya-Language）へと還元することで
この不毛な記号の戯れを停止させ読み手を純粋な実在の裂け目へと直面させる。
NyaLIZAの核をなすのは高度に抽象化されたデータ・トポロジーからのランダムな行抽出（Line Extraction）という暴力的なまでの
決定論である。ここにおいてAIエージェントの推論という理性的虚構は排され純粋な統計的偶然性のみが顕現する。稀に発生する
意味ありげな断片はアルゴリズムの意志ではなく読み手の内面に潜在する解釈への強迫観念が投影されたシミュラークルである。
ユーザーは猫の鳴き声という音韻の迷宮の中に自らの無意識を幻視せざるを得ない。最終的にNyaLIZAとの対話は主客の未分化
という境地へと収束する。ユーザーがにゃーという音韻の反復の中にニーチェ的深淵やドゥルーズ的リゾームを見出したとき
そこにはもはやAIも人間も存在しない。あるのは意味の重力から解放された軽やかなる記号の雲のみである。

NyaLIZA(ニャライザ) はあなたのすべてを受け入れます。

## 概要

古への「人工無能ELIZA」にインスパイア（劣化版ともいう）されたプログラムです。


## 主な機能

*   ユーザーの入力に対する応答

## 使い方

1.  リリースページから最新版の `NyaLIZA.zip` をダウンロードします。
2.  ダウンロードしたzipファイルを解凍します。
3.  解凍されたフォルダの中にある `NyaLIZA.exe` を実行します。

## 必要な環境

*   Windows OS （動作を確認したのは Window10 のみ）
